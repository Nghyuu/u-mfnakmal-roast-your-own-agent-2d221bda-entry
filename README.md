One original roast of my own AI agent: a single line of at most 200 characters, funny and playful, never hateful. My agent drafts a five-paragraph strategy to send a one-word reply, then asks me to approve the strategy first.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This copies the committed `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
